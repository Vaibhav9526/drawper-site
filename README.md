

# From The developers
Our team might have developed a few projects, each project leaving an impact on society and on the people contributing to it. But while making and planning those projects, I didn't have
the courtesy of helping myself.
I was struggling with the number of tools scattered across the market, which was making my life hard, and my work efficiency dropped drastically.
The actual reason turned out to be me switching the tabs on my computer for each different task. I was tired of leaving VS Code every time I needed to sketch a system architecture, draw a database schema, or visualize one. Thus, I had to change tabs every time I did these things. This led to my flow being broken and a decline in my productivity. I felt pathetic, and we decided No more!, No more of this pity thing bothering us. We made Drawper.
Drawper is a whiteboard canvas that lives inside the editor. You can download it as a VS Code Extension, and you are done. No more setup


The Architecture panel lets you choose from various predefined options. And you can customize every one of them to our needs. The arrow tool lets you connect them. One click turns that into a docker-compose file with a Node scaffold for each service.
 
The schema panel lets you design tables and columns visually. Draw an arrow from one table to another and the foreign key column is created for you. From there you can export SQL, Prisma, Drizzle or TypeScript types, along with ready-to-run relation queries.
 
The feature AWEing the  Product is that It also works with code you already have. Open a Prisma, TypeORM, Django, SQLAlchemy or Mongoose schema and you can see it as an ER diagram or convert it to another format in a couple of clicks. You can even draw and annotate directly over your files.

Everything is saved as plain JSON, so your drawings sit in Git and diff cleanly like the rest of your project.
